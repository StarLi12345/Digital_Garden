# Digital Garden

> 一个属于自己的二次元数字花园。

## 项目愿景

Digital Garden 不是博客，不是知识库，也不是办公软件。

它是一个私人空间。

这里可以存放：

- 想法
- 回忆
- 故事
- 梦境
- 情绪
- 成长记录
- 收藏的图片与片段

随着时间推移，这些内容会逐渐形成属于自己的数字生命轨迹。

------

## 设计原则

### 1. 记录优先

任何功能都应服务于记录本身。

如果一个功能不能帮助用户更轻松地表达、保存或回顾自己，它就不是优先功能。

### 2. 私人空间

打开首页时，应当像推开自己的房门。

而不是打开一个后台管理系统。

### 3. 温暖而非效率

本项目不是生产力工具。

重点是陪伴、记忆与成长。

### 4. 长期主义

所有内容都应能被保存多年。

避免绑定特定平台或私有格式。

## 核心功能

### 编辑

- 所见即所得编辑器
- 图片拖拽与粘贴
- 自动保存
- 历史版本
- 草稿恢复

### 记忆

- 时光机
- 去年今日
- 历史同日
- 随机回忆

### 花园

- 首页鸟瞰
- 成长状态
- 最近记录
- 记忆绽放

### AI

- 自动摘要
- 标签建议
- 回忆关联
- 长期成长分析

------

## 非目标

- 工作流系统
- 项目管理工具
- 即时通讯
- Notion 全量复刻
- Obsidian 全量复刻

## 最终目标

多年以后。

当我打开这个花园时。

我能够看见过去的自己曾经想过什么、爱过什么、经历过什么。

这里保存的不是文件。

而是人生留下的痕迹。
