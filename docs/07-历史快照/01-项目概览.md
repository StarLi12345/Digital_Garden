# Digital Garden — 数据花园

A personal "Data Garden" (数据花园) built with Next.js 16 + React 19 + Tailwind CSS 4 + TipTap + Prisma (SQLite).

**Why:** User wants a personal space for recording everything — a Notion/Feishu-like editor, Live2D companion, rich themes, and a "garden" concept emphasizing time-based growth.

**How to apply:**
- Run dev server: `cd "d:\Star's Blog+" && node node_modules/next/dist/bin/next dev`
- Runs on http://localhost:3000
- 4 main pages: `/` (home), `/garden` (timeline), `/plant` (editor), `/settings`
- Background music tracks in `public/audio/`, images in `public/backgrounds/`, resources in `resource/`

**Key Features Built:**
- 4 themes: garden, moonlight, sakura, rain (each with light/dark)
- Background system: image/video URL, drag-drop upload, opacity & blur sliders
- Ambient effects: petals, dust, snow, rain, geometry (canvas-based)
- Mouse follower: petals, dust, snow
- Time & weather adaptive theme runtime
- 16-track BGM system with custom upload, playlist, volume control
- TopBar: fixed/sticky + auto-hide mode
- Sidebar: collapsible with nav
- Companion widget: draggable chat with character expressions, API integration
- TipTap editor: H1-H5, bold/italic/underline, color picker, callout, task list, code block, quote, image/video/audio/links
- Hover "+" block menu (Notion-style inline)
- Wiki internal linking with `[[]]` syntax
- Drag-drop file upload in editor
- UI personalization: 8 font families, 10-48px size, 5 weights, italic, letter spacing, line height 1.0-3.0, block spacing 8-120px, paragraph spacing
- Theme color: 12 presets + custom color picker with confirm button
- Text color: custom color picker
- Home page: module visibility toggle + drag-to-rearrange modules
- Garden page: visual timeline with seasonal icons, search, type/tag filters
- Home page stats: entry count, tag count, monthly breakdown, garden memory

**Tech Stack:** Next.js 16.2.6, React 19.2.4, Tailwind CSS v4, TipTap v3.24, Prisma v5.22 (SQLite), Framer Motion v12, TypeScript
