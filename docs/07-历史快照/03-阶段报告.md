# Digital Garden（数据花园）— 阶段报告

> 报告日期：2026-06-02  
> 运行地址：http://localhost:3000  
> 技术栈：Next.js 16 + React 19 + Tailwind CSS 4 + TipTap + Prisma + Framer Motion

---

## 一、项目定位

**"有时间感的个人空间"** — 不是工具型编辑器，而是一个随时间生长的记录系统。核心是 Notion/飞书风格的强大编辑器 + Live2D 看板娘 + 可深度定制的花园主题。

---

## 二、页面结构（4 个主页面）

| 页面 | 路由 | 功能 |
|------|------|------|
| 首页 | `/` | 时间问候、动画统计数字、标签云、月度花园、随机回忆、最近记录 |
| 花园 | `/garden` | 可视化时间轴（季节图标）、搜索/类型/标签筛选、列表/时间双视图 |
| 种植 | `/plant` | Notion 风格编辑器：封面图 + 大标题 + `/`斜杠 + 悬停`+`号 + `[[`内部引用 |
| 设置 | `/settings` | 6 个可折叠拖拽分组（外观/动态/排版/音乐/伙伴/首页） |

## 四、主题与外观系统

**4 套花园主题**（每种含亮/暗双模式）：

| 主题 | 基调 | 主色 |
|------|------|------|
| 🌿 花园 (garden) | 温暖草木 | #6b8c5c |
| 🌙 月夜 (moonlight) | 暗色月光 | #c9a96e |
| 🌸 樱庭 (sakura) | 柔和樱粉 | #c97a8b |
| 🌧 雨 (rain) | 清冷雨蓝 | #6b8d9e |

**背景系统**：
- 全屏图片/视频/GIF（URL + 本地上传 + 拖放）
- 透明度 5%-98% 可调
- 模糊 0-50px 可调
- React 组件渲染（非 CSS 伪元素），即时响应
- 页面横幅（导航栏下方全宽 banner，可拖拽定位，高度 80-400px）

**Design Token 体系**（仿 Element Plus）：
- 阴影 4 级、间距 6 级（4px 基准）、圆角 4 级、字号 6 级、Z-Index 3 级
- 全局 `*:focus-visible` 聚焦光环

## 五、Live2D 看板娘系统

| 功能 | 实现 |
|------|------|
| 模型 | 4 个预设（小春/静久/小春校服/千岁）+ 自定义 URL + 文件夹上传 |
| 位置 | 右下角固定，live2d-widget CDN 加载 |
| 对话 | 底部输入栏 → Live2D 头顶气泡 → 语音朗读 |
| 语音 | 7 种女声音色（晓晓/晓双/晓伊/晓涵/晓梦/晓墨）+ 云希男声，pitch/rate 可调 |
| API | OpenAI 兼容格式（DeepSeek/GPT/Ollama），含花园知识库系统提示词 |
| 知识库 | 实时感知花园状态（记录数/标签数/本月活跃度），可本地智能应答 |
| 显示 | 可隐藏（🌸按钮恢复） |

## 十一、数据库（Prisma + SQLite）

- **Entry** — 标题/类型/内容(TipTap JSON)/Markdown/摘要/标签/时间
- **Tag** — 标签名/别名
- **EntryTag** — 多对多关联
- **Asset** — 附件（预留）

当前测试数据：**50 条笔记**，覆盖 6 种类型（回忆/想法/情绪/梦境/故事/学习），31 个标签，跨度 6 个月。
