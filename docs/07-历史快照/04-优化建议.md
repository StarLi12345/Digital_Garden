## 二、同类项目调研

### 2.1 数字花园类

| 项目 | 亮点 | 可借鉴 |
|------|------|--------|
| **Maggie Appleton V2** | 流体排版、Canela 字体、宽松留白、半成型想法 | 设计语言、"持续生长"的叙事 |
| **Flowershow** | Obsidian 兼容、`[[wiki]]`、Callout、KaTeX、TOC | 双向链接、MDX 管道 |
| **Knowledge Vault** | D3.js 知识图谱、类型化关联（"引用"/"基于"/"相关"） | **笔记间关系可视化** |
| **Quartz** | 图视图、反向链接、本地 Markdown | 内容发现 UX |

### 2.2 编辑器类

| 项目 | 亮点 | 可借鉴 |
|------|------|--------|
| **BlockNote** | 拖放排序、流畅动画、Slash 菜单、Mantine UI | **编辑器交互升级** |
| **Novel** | AI 自动补全、极简 UI、Vercel 设计 | AI 写作辅助 |
| **Plate** | shadcn/ui 深度整合、插件体系 | 组件化编辑器架构 |

### 2.3 最佳实践总结

1. **shadcn/ui + Tailwind** — 2024 年标配，可访问性好
2. **MDX + Content Layer** — 内容与表现分离
3. **双向链接 + 图谱** — 数字花园的核心特征
4. **渐进式复杂度** — Maggie 的"半成型想法"哲学

## 三、优化方案（按优先级）

### 🔴 P0 — 核心体验

1. **笔记关联系统**
   - 笔记详情页底部显示"引用此笔记"和"此笔记引用"的反向链接
   - 编辑器中 `[[` 已支持创建链接，但缺少反向查询
   - 新增 `relatedEntries` server action

2. **编辑器体验升级**
   - 借鉴 BlockNote：拖放块排序、Tab 缩进、平滑动画
   - 优化 Slash 菜单：分组、搜索、最近使用
   - 优化 placeholder 和空状态引导

### 🟡 P1 — 重要提升

3. **内容发现**
   - 知识图谱页面（D3.js force graph）
   - 标签聚合页
   - "随机漫步"按钮

4. **响应式优化**
   - 花园/设置/种植页移动端适配
   - 导航栏移动端汉堡菜单

5. **设计一致性**
   - 统一使用 Design Token（shadow/spacing/radius/color）
   - 清理未使用的 CSS

### 🟢 P2 — 锦上添花

6. **AI 花园伴侣重做**
   - 学习 BlockNote/Novel 的 AI 集成模式
   - 轻量级：仅 `L2Dwidget.alert()` + 简单输入

7. **性能优化**
   - ISR 静态生成花园页
   - 图片懒加载

8. **代码整理**
   - `settings/page.tsx` 拆分
   - 抽离公共 hook
