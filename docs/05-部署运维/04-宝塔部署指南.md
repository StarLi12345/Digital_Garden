## 每次部署（2 步）

### 第 1 步：本地打包 + 上传

在 VS Code 终端（Git Bash）打包：

```bash
cd "d:/Star's Digital_Garden"

# 打包（排除 node_modules、.next、git、本地数据库）
tar --warning=no-file-changed -czf garden-deploy.tar.gz \
  --exclude='node_modules' \
  --exclude='.next' \
  --exclude='.git' \
  --exclude='*.tar.gz' \
  --exclude='*.zip' \
  --exclude='resource' \
  --exclude='melotts-server' \
  --exclude='.tmp-live2d' \
  --exclude='.tmp-models' \
  --exclude='memory' \
  --exclude='snapshots' \
  --exclude='docs' \
  --exclude='*.bak' \
  --exclude='prisma/dev.db' \
  --exclude='.env' \
  --exclude='.env.local' \
  --exclude='.DS_Store' \
  .
```

然后**宝塔面板** → 「文件」→ 进入 `/www/wwwroot/garden/` → 点击「上传」→ 选择 `d:\Star's Digital_Garden\garden-deploy.tar.gz`

> 💡 文件约 200MB，需要 2-5 分钟上传。

### 第 2 步：服务器解压 + 构建 + 重启

上传完成后，去**云服务器控制台**（阿里云 ECS → 执行命令）执行：

```bash
#!/bin/bash
cd /www/wwwroot/garden

# 解压覆盖
tar -xzf garden-deploy.tar.gz

# 构建（约 2-3 分钟）
npm run build 2>&1 | tail -10

# 重启
pm2 restart garden --update-env

# 清理
rm -f garden-deploy.tar.gz

# 验证
sleep 2
curl -s -o /dev/null -w "首页 HTTP: %{http_code}\n" http://localhost:3000/
```

看到 `首页 HTTP: 200` 即部署成功，访问 `https://starli-digital-garden.cn/` 确认。

## 常见问题速查

| 症状 | 原因 | 修复 |
|------|------|------|
| 站点完全空白 | `.env` 缺失或 `DATABASE_URL` 错误 | 确认 `.env` 内容为 `DATABASE_URL="file:./dev.db"` |
| 图片/音频 404 | `public/` 静态资源未上传 | 打包时确保包含 `public/audio`、`public/backgrounds`、`public/carousel`、`public/resources` |
| 笔记列表为空 | 数据库连接问题 | `sqlite3 prisma/dev.db "SELECT COUNT(*) FROM Entry;"` 确认有 52 条 |
| 设置页面报错 | SSR 中 `localStorage` 未定义 | 不影响核心功能，设置页会自动降级客户端渲染 |
| 部署后不生效 | PM2 未重启或缓存 | 执行 `pm2 restart garden --update-env` 并强制刷新浏览器 `Ctrl+Shift+R` |

## 首次部署（新服务器初始化）

如果服务器从零开始，额外需要：

```bash
# 1. 上传整个项目（包含 node_modules 和 .next 则跳过构建）
# 2. 创建 .env
cat > /www/wwwroot/garden/.env << 'EOF'
DATABASE_URL="file:./dev.db"
GARDEN_USERNAME="Star.Li"
GARDEN_PASSWORD="123456"
EOF

# 3. PM2 启动
cd /www/wwwroot/garden
pm2 start npm --name garden -- run start
pm2 save
```
