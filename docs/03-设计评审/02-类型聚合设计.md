> 设计评审文档
>
> 目标：让系统第一次对用户产生"观察"。
> 不是统计面板，不是 Dashboard，不是 KPI。

## 一、数据获取方案

### 数据来源

当前首页已调用 `listEntries(1000)`，返回全量 Entry（含 `type` 和 `createdAt`）。

**不需要新增 Server Action。** 所有数据已在前端可用。

### 本月数据过滤

```typescript
const now = new Date();
const monthStart = new Date(now.getFullYear(), now.getMonth(), 1);

// 本月创建的 Entry（按 createdAt，不是 updatedAt）
const thisMonth = entries.filter(
  (e) => new Date(e.createdAt) >= monthStart
);

// 上月数据（用于对比）
const lastMonthStart = new Date(now.getFullYear(), now.getMonth() - 1, 1);
const lastMonth = entries.filter(
  (e) => new Date(e.createdAt) >= lastMonthStart
       && new Date(e.createdAt) < monthStart
);
```

### 为什么不需要后端改动

- `listEntries` 已返回包含 `type` 和 `createdAt` 的全量数据
- 月份过滤和聚合是纯客户端计算——1000 条 Entry 的 filter + reduce < 1ms
- 不需要分组查询、不需要新增 API

## 二、聚合方案

### 本月各类型计数

```typescript
const typeCounts: Record<string, number> = {};
for (const t of ENTRY_TYPES) typeCounts[t] = 0;
for (const e of thisMonth) typeCounts[e.type]++;

// 排序：数量多 → 少
const sorted = Object.entries(typeCounts)
  .filter(([, count]) => count > 0)
  .sort(([, a], [, b]) => b - a);
```

### 与上月对比

```typescript
const lastMonthCounts: Record<string, number> = {};
for (const t of ENTRY_TYPES) lastMonthCounts[t] = 0;
for (const e of lastMonth) lastMonthCounts[e.type]++;

// 总量变化
const thisTotal = thisMonth.length;
const lastTotal = lastMonth.length;
const trend = thisTotal > lastTotal ? "up" : thisTotal < lastTotal ? "down" : "same";
```

### 占比最高的类型

```typescript
const dominant = sorted[0]; // [type, count]
const dominantRatio = dominant[1] / thisTotal; // e.g. 0.45
```

## 三、文案生成规则

### 核心原则

1. **温和**：不带评价色彩。"你更多地在思考" 不是 "你过于理性"
2. **克制**：只描述客观趋势，不推断心理状态
3. **自然**：像朋友在聊天，不像报告
4. **不强制**：数据不足时不硬编文案

### 规则引擎（优先级从高到低）

```
如果本月 0 条记录：
  → 不显示"本月你的花园"区域

如果本月 < 3 条记录：
  → 不生成总结文案，仅显示类型计数

如果占比最高类型 > 50%：
  → "最近的你似乎更关注{TYPE_LABEL}。"
  例："最近的你似乎更关注学习。"

如果 情绪占比 > 30%：
  → "这个月你记录了不少情绪。"
  （不做情绪判断——不说"你情绪波动大"）

如果 梦境占比 > 30%：
  → "你最近似乎经常记得自己的梦。"

如果 上月总量 > 本月总量的 2 倍：
  → "和上个月比起来，这个月记录得少了一些。"
  （不做价值判断——不说"你松懈了"）

如果 本月总量 > 上月总量的 2 倍：
  → "这个月你比上个月更频繁地记录。"

默认（各类型均匀分布）：
  → "你的记录分布在不同的角落。"
```

### 文案结构

```
┌─────────────────────────────────────────────┐
│    本月你记录了                               │
│                                              │
│    想法   18 条                              │
│    学习   12 条                              │
│    情绪    3 条                              │
│                                              │
│    最近的你似乎更关注思考与规划。               │
└─────────────────────────────────────────────┘
```

### 文案措辞规范

| ✅ 允许 | ❌ 禁止 |
|--------|--------|
| "最近的你似乎更关注..." | "你的心理状态..." |
| "这个月记录得少了一些" | "你懈怠了" |
| "你最近似乎经常记得自己的梦" | "你的梦境很丰富"（太主观） |
| "和上个月比起来..." | "环比下降 XX%"（太数据化） |
| 一句话总结 | 多段分析 |

## 四、UI 草图

### 首页布局（新增区域位置）

```
┌──────────────────────────────────────┐
│  早上好 · Digital Garden              │  ← 问候（已有）
│  欢迎回到你的花园                     │
├──────────────────────────────────────┤
│  12 条记录    8 个标签                │  ← 统计（已有）
├──────────────────────────────────────┤
│  🌱 本月你的花园              🆕      │
│  ┌────────────────────────────────┐  │
│  │                                │  │
│  │  想法    18 条  ████████████   │  │  ← 类型条
│  │  学习    12 条  ████████       │  │
│  │  情绪     3 条  ██             │  │
│  │                                │  │
│  │  最近的你似乎更关注思考与规划。 │  │  ← 自然语言总结
│  └────────────────────────────────┘  │
├──────────────────────────────────────┤
│  🌿 来自花园                         │  ← 回忆卡片（已有）
├──────────────────────────────────────┤
│  最近记录          [✏️ 写点什么]      │  ← 最近记录（已有）
└──────────────────────────────────────┘
```

### 视觉权重设计

| 区域 | 视觉权重 | 理由 |
|------|:--:|------|
| 问候 | 强 | 每次打开的第一眼 |
| 统计卡片 | 中 | 快速了解花园规模 |
| **本月你的花园** | **中强** | **新区域，用户会多看几秒** |
| 来自花园 | 中 | 偶然遇见 |
| 最近记录 | 中 | 主动查找 |

### 样式设计

- 类型条使用 `bg-muted` 进度条风格（非彩色——不是 Dashboard）
- 每行的百分比条用 `bg-primary/30` 填充
- 文案用 `text-sm text-muted-foreground`，带 `"` 引用风格或 `—` 前缀
- 区域标题 `🌱 本月你的花园` 与"来自花园"一致的 muted 大写风格

### 显示条件

| 条件 | 行为 |
|------|------|
| 本月 0 条记录 | 不显示"本月你的花园"区域 |
| 本月 1-2 条 | 只显示类型计数，不生成总结文案 |
| 本月 ≥ 3 条 | 显示完整区域（计数 + 文案） |
