### 为什么三个人就够了

传统团队 10+ 人做的事，这里 3 个角色全包了：

| 传统团队 | 本项目 | 为什么能省 |
|----------|:------|------------|
| 前后端各 2-3 人 | Claude 一人 | AI 全栈覆盖，无沟通成本 |
| 架构师 1 人 | ChatGPT | 专注设计，不被实现细节拖慢 |
| PM + QA + 运维 + 市场共 4-5 人 | Star.Li 一人 | 项目规模可控，决策链短 |
| 技术文档 1 人 | Claude | 写代码的同时出文档，不脱节 |

产品、开发、测试、运维、安全、文档、宣发——标准团队要 10+ 人，这里 3 个角色全包。不是因为人少，是因为每个人都在做自己最擅长的事，而且**没有内部会议**。

- 🔴 删除 API 任意用户漏洞
