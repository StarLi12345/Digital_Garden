## 4.0.1 补充 — 2026-06-18（第二轮）

### 安全加固 + 账户完善 + 性能优化

**安全修复**：
- 🔴 删除 API：只能删除自己，加 garden-auth 校验
- 🟠 头像 API：加 garden-auth 校验，访客不能改他人头像
- 🟡 Cookie `secure` 统一：3 处改为 `request.url.startsWith("https://")`
- 🔒 切换账号 API：设备本地记忆（localStorage ID 列表），API 动态获取头像
- 🚫 注册限流：同 IP 每分钟最多 3 次，防脚本批量注册

**账户功能**：
- 修改用户名：`PUT /api/auth/username` + 账号页 inline 编辑（2-20 字符，中英文数字下划线点号，重名校验）

**统计系统**：
- 首页全局统计：次访问 + 今日访客，与「条记录」「个标签」并列，grid-cols-2/sm:grid-cols-4 移动端适配
- 账号页统计：改为「我的笔记访问」（通过 `?userId=` 参数过滤）

**性能优化**：
- 首页：`listEntries(1000)` → `getGardenStats()`（仅返回计数）+ `listEntries()`（默认 20 条）
- 花园：`listEntries(1000)` → `listEntries(500)`

**切换账号头像修复**：
- 不再将 data URL 存 localStorage → 改为存用户 ID 列表，通过 `/api/auth/users?ids=` API 实时获取头像
- 图片加载失败自动回退首字母
