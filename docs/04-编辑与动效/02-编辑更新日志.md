## E2 — Link（2026-05-31）

### 新增能力

| 能力 | 类型 | 工具栏 | 说明 |
|------|------|:--:|------|
| 🔗 超链接（Link） | 行内 | ✅ | 选中文字 → 点击按钮 → 输入 URL → 生成链接 |

### 工具栏变化

```
[H2] [H3] [B] [I] [•] [1.] [</>] [❝] [🌱] [—] [🔗] [↩] [↪]
                                        引用  便签  分割  链接
```

### 编辑体验变化

**Link**：
- 选中文字 → 点击 🔗 → 输入 URL → 创建链接
- 光标在已有链接上 → 点击 🔗 → 移除链接（toggle 行为）
- 链接在编辑态不可点（`openOnClick: false`），避免误触
- 链接在阅读态可点击（`target="_blank"`），新标签页打开
- 链接样式：primary 色 + 下划线 + hover 变深
- Markdown 转换：`[link text](url)` 格式正确输出

**已知限制**：

1. 链接输入使用浏览器 `window.prompt`——受限于简单交互
2. 不支持编辑已有链接 URL（只能删除后重新创建）
3. 不解析/不预览链接标题、favicon

## E1 — Callout + Divider（2026-05-31）

### 新增能力

| 能力 | 类型 | 工具栏 | 说明 |
|------|------|:--:|------|
| 🌱 花园便签（Callout） | 块级 | ✅ | 暖色便签块，标记"留给自己的重要内容" |
| — 分割线（Divider） | 块级 | ✅ | 视觉分隔不同主题的内容 |

### 工具栏变化

```
之前: [H2] [H3] [B] [I] [•] [1.] [</>] [❝] [↩] [↪]
之后: [H2] [H3] [B] [I] [•] [1.] [</>] [❝] [🌱] [—] [↩] [↪]
                                        ^^^^  ^^
                                        🆕    🆕
```

新增 2 个按钮：
- `🌱` — 花园便签（toggle callout）
- `—` — 分割线（insert horizontal rule）

### 编辑体验变化

**Callout**：
- 点击 `🌱` 按钮 → 切换当前块的 Callout 状态
- Callout 内按 Enter → 在便签内新建段落（不退出）
- Callout 内空白时按 Backspace → 退出便签
- 编辑态视觉：暖色背景 + accent 左边框 + 正体文字
- 键盘快捷键：`Ctrl+Shift+C`（未来支持）

**Divider**：
- 点击 `—` 按钮 → 在光标位置下方插入分割线
- 编辑态与阅读态一致的 `<hr>` 样式

### 与 Blockquote 的视觉区分

| | Blockquote | Callout |
|------|:--:|:--:|
| 工具栏 | ❝ | 🌱 |
| 边框颜色 | border（灰色） | accent（陶土色） |
| 背景 | 无 | 暖色（#fdf5f0 / #2a221d） |
| 字体样式 | 斜体 | 正体 |
| 文字颜色 | muted | foreground |
| 语义 | 引用别人 | 珍藏自己 |

### 已知限制

1. Callout 不支持嵌套 Callout（内部不能再有 Callout）
2. Callout 不支持类型切换（只有一种暖色风格）
3. Divider 不支持通过 Backspace 删除（与 TipTap 默认行为一致）
4. `Ctrl+Shift+C` 键盘快捷键待后续实现
